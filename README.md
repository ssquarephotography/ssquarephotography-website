# SSQUARE Photography Website

Upload all files to the root of your GitHub repository.

GitHub Pages:
Settings > Pages > Branch main > /root > Save

CMS:
Open https://www.ssquarephotography.com/admin/
Login with GitHub.

Important:
If CMS login does not open, enable GitHub OAuth using Netlify Identity or Cloudflare Pages/Decap Git Gateway alternative.
Static website will work immediately on GitHub Pages.
